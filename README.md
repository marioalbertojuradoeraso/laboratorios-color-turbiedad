# Laboratorios del agua: color y turbiedad

Dos experiencias educativas en español, con ilustraciones, narración y simulaciones interactivas.

- `color/index.html`: color del agua.
- `turbiedad/index.html`: turbiedad, tubo de observación y turbidímetro con curva de calibración.
- `index.html`: acceso a ambas experiencias.

Los archivos HTML incluyen sus recursos multimedia. También se pueden descargar y abrir localmente sin conexión. No requieren claves API del estudiante.

Publicación prevista con GitHub Pages desde la raíz de la rama `main`.
